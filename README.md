# 校园学习助手 CampusStudy

一个面向 **HarmonyOS PC** 的轻量校园学习规划与课程管理应用。

把学生日常最高频的四件事收进一个应用：**课表、作业、计划、成绩**。

## 功能模块

| 模块 | 解决什么问题 |
| --- | --- |
| 课程表管理 | 「下节课在哪、几点上」——周视图一目了然 |
| 作业 / 任务待办 | 「还有什么没交」——截止日期不再漏 |
| 学习计划 | 「这周要干什么、做到没有」——目标与打卡 |
| 成绩 / 学分统计 | 「绩点多少、学分够没够」——自动计算 |

## 技术栈

- **开发工具**：DevEco Studio
- **语言**：ArkTS（基于 TypeScript）
- **UI 框架**：ArkUI 声明式
- **数据存储**：`@ohos.data.relationalStore`（本地 RDB）
- **目标形态**：鸿蒙 PC（`deviceTypes` 含 `"2in1"`）

## 设计原则

1. **简单优先** —— 核心流程不超过 2 层页面，添加课程、勾掉作业都在 3 步内完成。
2. **PC 大屏适配** —— 不照搬手机单列布局，采用「左侧导航 + 右侧内容区」双栏结构，课表横向铺满。
3. **离线可用** —— 数据全部本地存储，不依赖网络与登录，打开即用。
4. **可扩展** —— 数据层与 UI 层解耦，后续加课表导入、多学期切换不用重构。
